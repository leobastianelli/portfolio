title: Onefam Community Portal
role: Full-stack developer

## Summary
Programa de membresía para una cadena europea de hostels. Los huéspedes se suscriben, acumulan cashback por sus reservas y lo canjean en recepción al hacer el check-in.

## Technical
Next.js en Vercel, Supabase para usuarios, autenticación mediante el customer ID de Stripe con alta automática, tres niveles de suscripción, un ledger de cashback y una integración con la API de Cloudbeds para aplicar el crédito sobre la reserva.
